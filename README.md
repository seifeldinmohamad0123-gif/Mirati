# مِرآتي | Mirati

واجهة أولية عربية لتطبيق شخصي يساعد المستخدم على استكشاف ذاته وتدوين أفكاره وأهدافه ولحظاته.

## بناء APK
- افتح تبويب **Actions** في المستودع.
- اختر **Build Mirati APK** ثم **Run workflow**.
- بعد نجاح المهمة، افتح تفاصيل التشغيل ونزّل artifact باسم **Mirati-debug-apk**.
- يحتوي الملف المضغوط على `app-debug.apk`.

## ملاحظات
هذه نسخة أولية قابلة للبناء، وتضم واجهة WebView محلية. أقسام تدوين الذات الحالية تحفظ البيانات محليًا داخل المتصفح/التطبيق، ولا يوجد خادم أو مزامنة سحابية في هذه المرحلة.
